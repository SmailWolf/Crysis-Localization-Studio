# Інструкція CryLocal

CryLocal відкриває мовний PAK гри, дає перекладати текст вручну або через локальну TranslateGemma 4B, зберігає роботу у проєкті й збирає окремий PAK. Програма не змінює файли гри автоматично.

## 1. Запуск і створення проєкту

### Windows 10/11 x64

1. Завантажте й розпакуйте Windows-пакет CryLocal повністю в окрему папку.
2. Запустіть `Start CryLocal.cmd`.
3. Якщо використовуєте вихідний архів, спершу запустіть `windows/setup.ps1` у PowerShell; він підготує переносні Python і PySide6.

### Linux

Потрібні Python 3.10+ і PySide6. У терміналі в папці програми виконайте `python3 -m pip install -r requirements.txt`, а потім запустіть `./launch.sh`.

### Новий проєкт

1. У списку **Гра / Game** виберіть Crysis 1, Crysis 2 або Crysis 3 Remastered.
2. Натисніть **Новий проєкт / New project**.
3. Виберіть мовний PAK потрібної гри, зазвичай `english.pak`.
4. Вкажіть ім’я та місце для файла проєкту. Зберігайте проєкт поза папкою гри.

Кожен проєкт прив’язаний до конкретних XML-файлів вихідного PAK. Якщо PAK не відповідає проєкту, створіть новий проєкт для цієї версії гри. Crysis 2/3 Remastered ще не перевірені на реальних PAK.

## 2. Вибір мов

У списку **Мова перекладу / Translation language** виберіть цільову мову. Українська встановлена спочатку. Проєкт зберігає тексти окремо для кожної мови, тому можна перемикатися між мовами без втрати попередньої роботи.

Мову оригіналу виберіть у **Налаштуваннях / Settings** моделі. Вбудована модель TranslateGemma підтримує 55 мов; у списку CryLocal доступні 45 мов. Вибрана мова інтерфейсу програми (English або Українська) не змінює мови перекладу.

## 3. Переклад вручну

1. Знайдіть рядок через пошук або фільтри. Таблиця показує оригінал, ключ і стан перекладу.
2. Виділіть рядок. Нижче з’являться оригінал, контекст і поле перекладу.
3. Перекладіть самостійно: натисніть **Копіювати оригінал / Copy source**, вставте його у свій редактор чи перекладач, скопіюйте готовий текст і натисніть **Вставити переклад / Paste translation**. Або введіть текст прямо у поле.
4. Збережіть проєкт через **Ctrl+S**. **Ctrl+Enter** застосовує текст і переходить до наступного рядка.

Не змінюйте службові вставки на кшталт `%s`, `{0}`, `@ключ` і XML-тегів. Кнопка **Перевірити / Validate** знаходить типові помилки, але не оцінює якість перекладу.

## 4. Переклад через TranslateGemma 4B

1. Натисніть **Завантажити 4B / Download 4B**. CryLocal завантажить TranslateGemma 4B Q4_K_M (близько 2,49 ГБ) і відповідний llama.cpp. Потрібне інтернет-з’єднання та приблизно 3 ГБ вільного місця.
2. Після завантаження виберіть цільову мову у головному вікні. За потреби змініть мову оригіналу в **Налаштуваннях / Settings**.
3. Виділіть рядок і натисніть **Перекласти рядок / Translate row**. Результат з’явиться в полі редагування, його можна виправити вручну.
4. Для групи рядків натисніть **Перекласти групу / Translate batch**. Оберіть виділені рядки або результати пошуку та ліміт. Заповнені рядки активної цільової мови пропускаються.
5. Пакетний переклад створює резервну копію проєкту й журнал відновлення. Переклад працює локально на CPU; перший запуск може бути повільним. Завантажена модель не потребує інтернету для подальшої роботи.

За бажанням у **Налаштуваннях** можна під’єднати вже запущений сумісний сервер LM Studio, llama.cpp або Ollama.

## 5. Імпорт і експорт CSV

1. Натисніть **Експорт CSV / Export CSV**.
2. Відредагуйте колонку `translation` у табличному редакторі. Не змінюйте `id` та `source`.
3. Для імпорту натисніть **Імпорт CSV / Import CSV**, виберіть збережений файл, потім натисніть **Зберегти**.

CSV має кодування UTF-8 із BOM. Проєкт допускає багаторядкові клітинки. Перевірте імпорт і збережіть резервну копію, перш ніж продовжити роботу.

## 6. Збирання та встановлення мовного PAK

1. Збережіть проєкт і запустіть **Перевірити / Validate**.
2. Натисніть **Зібрати PAK / Build PAK** та збережіть результат у нове місце поза папкою гри. Для нестандартних літер виберіть сумісний PAK тієї самої гри й версії зі шрифтом, що вже містить потрібні символи. Наприклад, для української перевірте наявність `Ґ Є І Ї`, а для білоруської — `Ў І`.
3. Після збирання перевірте кількість замінених шрифтових ресурсів у вікні та список `font_assets_replaced` у звіті `.report.json`. Це перелік скопійованих файлів, а не перевірка підтримки гліфів. Закрийте гру й зробіть копію оригінального PAK.
4. Встановіть новий PAK вручну, замінивши копією однойменний файл базового мовного слота. Щоб бачити текст, у грі виберіть мову цього слота.
5. Якщо гра не запускається або текст відображається неправильно, поверніть резервну копію.

Переклад і модель не додають гліфи у шрифти. CryLocal копіює готові шрифтові ресурси з вибраного PAK у відповідні шляхи цільового PAK; вона не створює нові шрифтові файли. Тому звичайний `russian.pak` не гарантує українські `Ґ Є Ї` чи білоруську `Ў`. Перевірте у грі рядок із усіма потрібними літерами: порожні квадрати означають, що вибраний шрифт їх не містить. Утиліта не додає окремий пункт мови в меню гри. Збирання Crysis 2/3 Remastered на реальних PAK ще не перевірене.

## 7. Важливі файли та діагностика

- **Проєкт `.crylocal.json`** — поточні переклади й налаштування. Зберігайте його та резервні копії.
- **CSV** — зручний обмін текстом з іншими редакторами.
- **`.report.json`** — звіт про зібраний PAK.
- **Windows налаштування, модель та журнали** — `%LOCALAPPDATA%\CryLocal`.
- **Linux runtime** — папка `runtime/` поряд із програмою.

Якщо модель не запускається, натисніть **Зупинити / Stop**, перевірте, що модель завантажена, і спробуйте ще раз. Якщо PAK не відкривається, перевірте, що це мовний пакет саме цієї версії гри. Зашифровані PAK, бінарні CryXmlB, текст у зображеннях та редагування GFX-шрифтів не підтримуються.
