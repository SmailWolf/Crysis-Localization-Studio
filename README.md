# CryLocal

Настільна утиліта для ручної та AI-локалізації Crysis Remastered. Підтримує український та англійський інтерфейс, 45 цільових мов, імпорт і експорт CSV, а також TranslateGemma 4B, що працює локально.

## Запуск

Докладна покрокова інструкція: [GUIDE.uk.md](GUIDE.uk.md). Для Windows використовуйте переносний пакет і `Start CryLocal.cmd`. На Linux потрібні Python 3.10+ та інтернет для початкового встановлення PySide6: запустіть `./install-linux.sh`, потім `./launch.sh`. Створіть проєкт із мовного PAK вашої копії гри. Проєкт і файли гри не входять до цього репозиторію.

Для перенесення на інший комп’ютер: Python 3.10+ і `python -m pip install -r requirements.txt`. Для Windows використовуйте переносний пакет і `Start CryLocal.cmd`; окремий Python у ньому вже є. Якщо шлях до гри інший, створіть новий проєкт із вашого мовного PAK.

## Windows і мова інтерфейсу

1. Розпакуйте `CryLocal-Windows-x64.zip` повністю в окрему папку. Windows 10/11 x64.
2. Запустіть **`Start CryLocal.cmd`**. Python 3.14.8 і PySide6 6.12.0 вже включені; встановлення Python і права адміністратора не потрібні. Модель завантажується окремо кнопкою **Download 4B / Завантажити 4B**.
3. Праворуч угорі є **Interface language / Мова інтерфейсу**: English та Українська. Вибір зберігається й застосовується одразу. Мова інтерфейсу не змінює мову оригіналу чи перекладу гри.
4. Після перенесення проєкту натисніть **Locate PAK… / Знайти PAK…** і виберіть потрібний `english.pak`. Утиліта звірить вихідні XML перед зміною шляху. Для іншої версії гри створіть новий проєкт.
5. Налаштування, модель і журнали Windows-версії зберігаються у **`%LOCALAPPDATA%\CryLocal`**; проєкти можна зберігати у вибраній папці.

Переносний Windows-пакет має вбудовані Python і Qt, але не містить моделі 2,49 ГБ. Універсальний архів із вихідними файлами також має Windows-запускач: за відсутності `.python/` він завантажує перевірені компоненти через `windows/setup.ps1`.

Windows-компоненти взяті з [Python.org](https://www.python.org/downloads/release/python-3148/) і [PyPI](https://pypi.org/project/PySide6-Essentials/6.12.0/). Фіксовані версії, розміри й SHA-256 збережені у `windows/artifacts.json`; файли ліцензій включені у переносне середовище. Автоматизовані тести лежать у `test_*.py`.

## Вибір гри

У верхній частині вікна є список **Гра / Game**: **Crysis 1 Remastered**, **Crysis 2 Remastered**, **Crysis 3 Remastered**. Виберіть потрібну гру, потім її мовний PAK. Якщо проєкт уже відкритий, перемикання створює окремий проєкт із вибраного PAK; поточні зміни можна зберегти перед переходом. Скасування вибору PAK повертає попередню гру.

Вибір гри зберігається у проєкті як `game_id` і додається до звіту збирання. При відкритті проєкту правильна гра вибирається автоматично. Старі проєкти читаються: гра визначається за шляхом, а за відсутності впізнаваної назви використовується Crysis 1. Останній збережений проєкт відкривається при наступному запуску, якщо файл доступний. Діалог вибору PAK запам’ятовує папку окремо для кожної гри.

Профілі використовують визначення фактичного формату PAK/XML. Вибір Crysis 2 чи 3 не є підтвердженням сумісності конкретної версії цих ігор: їхні оригінальні файли ще не перевірялися.

Для командного рядка: `python crylocal.py new english.pak project.json --game crysis2-remastered`. Також доступні `crysis1-remastered` та `crysis3-remastered`.

## Ручний переклад

У списку **«Мова перекладу»** виберіть цільову мову. Вибір зберігається в проєкті, діє і для ручного введення, і для TranslateGemma. Українська вибрана за замовчуванням. Проєкт зберігає рядки окремо для кожної цільової мови; при перемиканні попередній переклад не зникає, а нова мова починається зі своїх збережених рядків. TranslateGemma офіційно підтримує 55 мов; у списку утиліти доступні 45, зокрема англійська, українська, польська, німецька, французька, іспанська, японська, корейська, арабська, китайська спрощена й традиційна. Мову оригіналу можна вибрати в налаштуваннях моделі.

1. Виберіть рядок. Оригінал і контекст з’являться знизу.
2. Натисніть **«Копіювати оригінал»**, перекладіть його у зручний спосіб, натисніть **«Вставити переклад»**. Можна просто набирати текст у правому полі; Ctrl+C / Ctrl+V також працюють.
3. **Ctrl+Enter** застосовує переклад і переходить далі. **Ctrl+S** зберігає проєкт. Зміни в поточному полі також застосовуються при виборі іншого рядка.
4. Пошук охоплює ключі, текст, переклад і контекст. Є фільтри за файлом і станом перекладу.

Для сторонніх редакторів використовуйте **«Експорт CSV» / «Імпорт CSV»**. Редагуйте колонку `translation`; залишайте `id` і `source` без змін. CSV має кодування UTF-8 із BOM; підтримуються багаторядкові поля. Помилковий імпорт не застосовується частково.

## TranslateGemma 4B усередині програми

1. Натисніть **«Завантажити 4B»**. Утиліта завантажить модель **TranslateGemma 4B Q4_K_M** (2,49 ГБ / 2,32 ГіБ) та середовище llama.cpp. Потрібно приблизно 3 ГБ вільного місця. Файли зберігаються в папці `runtime/` поруч із програмою.
2. Завантаження можна скасувати й продовжити. Перед використанням перевіряються розмір і SHA-256. Для повторного запуску завантаження натисніть ту саму кнопку.
3. **«Перекласти рядок»** автоматично запускає модель, одразу показує результат у редакторі й таблиці та підтверджує завершення повідомленням.
4. **«Перекласти групу»** обробляє виділені рядки або результати пошуку. Вибір кількох рядків: Ctrl / Shift. За замовчуванням обмеження — 50 рядків за запуск. Заповнені переклади пропускаються.
5. Перед пакетним перекладом створюється копія проєкту `.before-ai-…json`. Результати пишуться в журнал `.ai-…jsonl`, проєкт зберігається кожні 10 успішних рядків і після завершення. Скасування завершує поточний запит і зберігає вже отримані результати.
6. **«Зупинити»** вивантажує модель із пам’яті. При закритті програми її власний процес також завершується.

У **Налаштуваннях → Прискорення** виберіть **GPU · Vulkan** або **CPU**. GPU-режим завантажує Vulkan-версію llama.cpp і передає всі шари моделі відеокарті; потрібні сумісний драйвер і достатньо VRAM. Якщо GPU або пам’яті недостатньо, запуск повідомить про помилку; автоматичного переходу на CPU немає. CPU-режим можна вибрати вручну. Після завантаження інтернет для перекладу не потрібен. Програма не завантажує повний переклад у хмару: вбудований процес слухає лише `127.0.0.1`.

Модель завантажується на комп’ютер користувача під час першого встановлення. Вона працює локально; після завантаження переклад не потребує інтернету. Переклад моделі потрібно перевірити вручну.

Службові вставки (`%s`, `{0}`, `@ключ`, XML-подібні теги тощо) тимчасово маскуються, потім відновлюються та перевіряються. Якщо модель їх змінить або обріже відповідь, такий результат не записується. Переклад моделі потребує редакторської перевірки.

У **«Налаштуваннях»** можна змінити мову оригіналу (англійська / російська) або підключити зовнішній LM Studio / llama.cpp через сумісний HTTP API. Для зовнішнього сервера потрібні його адреса й точна назва завантаженої моделі. Вбудований режим підтримує автозавантаження для Linux x64 та Windows x64; Windows-бінарні файли Python та Qt додатково перевірені через Wine; на чистій Windows ця версія ще не перевірялася.

## Збирання локалізації

1. Натисніть **«Перевірити»**, виправте помилки службових вставок.
2. Натисніть **«Зібрати PAK»**. За бажанням укажіть `russian.pak` як донор шрифтів. Їхня наявність не гарантує підтримку всіх літер вибраної мови: перевірте її символи в самій грі.
3. Збережіть результат у окрему папку, наприклад `build/english.pak`. Програма створює повний мовний пакет, тому його розмір включає початкове озвучення. Поруч з’явиться звіт `.report.json`.
4. Для перевірки закрийте гру, збережіть резервну копію оригінального мовного PAK і скопіюйте зібраний пакет на його місце. У грі виберіть мову вихідного пакета. Текст цільової мови займає слот базового пакета; додавання нового пункту мови в меню гри утиліта не виконує.
5. Для відновлення поверніть резервну копію.

Утиліта сама не встановлює PAK у гру. Неперекладені записи, звук, інші ресурси та службові поля залишаються з базового пакета. Для перекладених записів текст записується як у вихідну, так і в перекладену колонку, щоб мовний слот оригіналу також міг його показувати. Джерельний текст зберігається в проєкті й CSV. Завантаження нового пакета та вигляд інтерфейсу потрібно перевірити в грі.

## Сумісність

- **Crysis Remastered:** читання і збирання перевірені на локальних `english.pak` і `russian.pak` користувача. Знайдено всі 8 XML-таблиць; звук та інші ресурси порівняні за вмістом після збирання. Гру для візуальної перевірки не запускали.
- **Crysis 2 / 3 Remastered:** передбачено пошук `Localized`, `Localization`, мовних `*.pak` / `*_xml.pak` і розбір таблиць за заголовками. На файлах цих ігор не перевірено. Схожий рушій не гарантує сумісності пакування та шрифтів.
- Підтримуються відкриті ZIP-сумісні PAK і текстовий SpreadsheetML XML. Шифровані PAK, CryXmlB, озвучення, редагування GFX-шрифтів і текст усередині зображень не підтримуються. Пропущені XML перелічуються в проєкті; повноту треба оцінювати для кожної гри.

## Командний рядок

```sh
python crylocal.py scan "/шлях/до/гри"
python crylocal.py new "/шлях/до/english.pak" project.json
python crylocal.py export project.json translations.csv
python crylocal.py import project.json translations.csv
python crylocal.py check project.json
python crylocal.py build project.json build/english.pak --fonts-from "/шлях/до/russian.pak"
python -m unittest -v
```

Ядро й командний рядок використовують стандартну бібліотеку Python. Віконний інтерфейс використовує PySide6.
